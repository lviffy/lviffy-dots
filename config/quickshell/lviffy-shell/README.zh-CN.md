# 💠 lviffy-shell

> **专为 lviffy-dots 打造的现代化 Quickshell 桌面环境。**

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

---

## 🌟 概述

`lviffy-shell` 是基于 [Quickshell](https://quickshell.outfoxxed.me/) 定制的高性能桌面 Shell，集成了 iOS/macOS 风格的控制滑块、快捷面板、Dock 栏以及通过 Matugen 实现的动态配色提取。

## 🚀 使用方法

Hyprland 在登录时会自动启动 `lviffy-shell`：

```bash
qs -c lviffy-shell
```
