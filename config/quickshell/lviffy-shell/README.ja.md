# 💠 lviffy-shell

> **lviffy-dots 用にカスタマイズされたモダンな Quickshell デスクトップ環境。**

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

---

## 🌟 概要

`lviffy-shell` は [Quickshell](https://quickshell.outfoxxed.me/) をベースにしたカスタマイズされたシェルです。iOS/macOS スタイルのスライダー、クイックトグル、Dock、Matugen による動的カラーパレット抽出を統合しています。

## 🚀 使い方

Hyprland 起動時に自動的に実行されます:

```bash
qs -c lviffy-shell
```
